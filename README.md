# Ortega Odontologia: site de clínica odontológica

Site de uma clínica odontológica, feito em HTML, CSS e JavaScript, em um único arquivo (`index.html`) mais as imagens.

## Recursos

- Imagens responsivas e otimização para celular.
- Carrossel de serviços e seção de Ortodontia.
- Botões de agendar que abrem a agenda online (Codental).
- Link do Instagram e identificação profissional (CRO) no site.

## Como ver

Abra o `index.html` no navegador.

## Observação

A marca, os textos e as imagens pertencem ao respectivo negócio.
